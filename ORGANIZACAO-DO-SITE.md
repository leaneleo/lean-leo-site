# Onde guardar os arquivos

Esta pasta central reúne o site Lean&Leofit e o sistema DivaFit.

- `img/`: imagens do site institucional existente.
- `videos/`: vídeos do site institucional existente.
- `css/` e `js/`: aparência e funcionamento do site institucional.
- `divafit/assets/imagens/`: imagens públicas do sistema DivaFit.
- `divafit/assets/videos/`: vídeos públicos do sistema DivaFit.
- `divafit/`: código do sistema, separado das páginas do site institucional.

Para adicionar uma imagem, guarde-a na pasta correspondente e diga onde ela
deve aparecer. O código precisa ser ajustado e enviado ao GitHub para publicar.
O Google Drive sincroniza arquivos; ele não envia alterações automaticamente
ao GitHub. Nesta pasta não foi configurado nenhum envio automático.

As publicações atuais usam o mesmo repositório `leaneleo/lean-leo-site`:

- Site institucional `leaneleo.com.br`: branch `main`, pasta raiz.
- Sistema `consultoria-divafit.netlify.app`: branch
  `codex/divafit-gestao-inicial`, pasta `divafit`.

Ao atualizar, deve-se preservar essa separação. Esta pasta do Drive é a
central de trabalho e materiais; o GitHub registra as versões publicadas.
Documentos privados dos alunos não devem ser enviados ao repositório público.
Uma cópia dos arquivos locais substituídos foi guardada na pasta de backup
informada na entrega. Os demais materiais existentes foram preservados.
