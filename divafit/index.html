DivaFit na tela inicial

Use o mesmo endereço do sistema e entre com seu acesso habitual. Os dados continuam compartilhados com a equipe.

Android · Chrome

  1. Abra o DivaFit no Chrome do celular.
  2. Toque no menu ⋮ e escolha Adicionar à tela inicial ou Instalar aplicativo.
  3. Confirme a instalação. Depois, abra pelo ícone DivaFit.

iPhone · Safari

  1. Abra o DivaFit no Safari.
  2. Toque em Compartilhar e depois em Adicionar à Tela de Início.
  3. Confirme em Adicionar.

Se estiver dentro de outro aplicativo, abra o link no Chrome ou Safari. A instalação é feita pelo navegador; esta versão não exige download pela loja.

É necessário estar conectado à internet para consultar e salvar dados de alunos.
